Localcrawl

Localcrawl is a local tool that reads web pages for an AI assistant (Claude Desktop), at the request of the person who uses it. It is operated by Idea Ninja, Portugal.

This page will explain how Localcrawl identifies itself, how it follows robots.txt and how to block it. It will be published with Localcrawl 0.5.0.
